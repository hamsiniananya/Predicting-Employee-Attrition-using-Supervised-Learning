# Predicting Employee Attrition using Supervised Learning

## Overview
This project predicts employee attrition using supervised machine learning algorithms on the IBM HR Analytics Employee Attrition dataset.

## Dataset
- IBM HR Analytics Employee Attrition Dataset
- 1,470 employee records
- 35 features

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- Bagging Classifier
- XGBoost

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

## Best Performing Model
Based on the evaluation metrics, Logistic Regression achieved the best overall performance and was selected as the recommended model for employee attrition prediction.
